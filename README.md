# Monthly Student Attendance Report

Convert daily student attendance Excel exports into monthly summary Excel reports.

## For End Users (Windows)
1. Download `AttendanceReport.exe` from the Releases page.
2. Double-click to run. No installation needed.
3. Select the attendance Excel and generate the report.

## For Developers (Mac)
```bash
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
